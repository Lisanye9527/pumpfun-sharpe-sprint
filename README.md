# Pump.fun Sharpe Sprint

[make.fun 竞赛页](https://make.fun/c/u-jackxyz72-pump-fun-sharpe-sprint-cleanest-03e4f532)

make.fun Sharpe Sprint 参赛纸面交易机器人，按小时 Sharpe 排名。策略为动量过滤 + 金字塔加仓 + 探针保底往返：对每条曲线一生只入场一次，只买已过启动期、窗口净流入为正、买家分散且价格贴近窗口高点的曲线；持仓 +10% 时半仓加仓一次，止盈/止损/追踪止损/时间止损任一触发即全仓退出；往返节奏落后时用小额探针单在流动性好的曲线上保底完成往返次数。
